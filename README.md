# git-calculator

A simple command-line calculator written in Python. It was built to practise
a Git and GitHub workflow: branching, pushing, pulling, and resolving merge conflicts.
This project was created for a DevOps assignment.

## How to run

You need Python 3 installed.

```bash
python calculator.py
```

Choose an operation from the menu, enter two numbers, and the result is printed.
Type `q` to quit.

## Features

- Addition, subtraction, multiplication and division
- Safe division (dividing by zero shows an error instead of crashing)
- Text menu that keeps running until you quit
- Modulo operation (remainder after division)
